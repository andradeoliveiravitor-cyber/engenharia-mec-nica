# Feira de Profissões — Engenharia Mecânica

Portfólio digital interdisciplinar desenvolvido para apresentação na **Feira de Profissões**.

## Estrutura do Projeto
- `index.html`: Estrutura semântica em HTML5 contendo as seções de Apresentação da Profissão, Fatos Históricos, Panorama Atual e Mercado de Trabalho, além dos Créditos.
- `style.css`: Estilização responsiva em CSS3 com paleta industrial (azul escuro e laranja), layout em Grid/Flexbox e gráfico de barras em CSS puro.

## Como Publicar no GitHub Pages
1. Faça upload dos arquivos `index.html` e `style.css` na raiz do seu repositório público.
2. Acesse **Settings > Pages** no repositório.
3. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
